# Learn with Mohanna 🌊

یک پلتفرم کامل، مدرن و هوشمند آموزش زبان انگلیسی برای فارسی‌زبان‌ها — از سطح مبتدی تا متوسط.

## 🎯 هدف

کمک به کاربران فارسی‌زبان برای یادگیری زبان انگلیسی از طریق یک اکوسیستم کامل شامل آموزش، تمرین، هوش مصنوعی، آزمون، ارتباط کاربران و پیگیری پیشرفت.

## ✨ ویژگی‌ها

- 🏠 صفحه اصلی جذاب و مدرن
- 📊 داشبورد یادگیری شخصی
- 📚 سیستم لغات تعاملی
- 📖 دیکشنری مدرن
- 🤖 دستیار هوش مصنوعی فارسی‌محور
- 📝 آزمون‌ها (لغات، گرامر، تعیین سطح، ترکیبی)
- 👥 انجمن کاربران امن
- 🎬 بخش فیلم و انیمیشن آموزشی
- 👤 پروفایل کاربر
- ⚙️ تنظیمات

## 🎨 هویت برند

- **رنگ اصلی:** Ocean Blue (آبی اقیانوسی)
- **رنگ مکمل:** Coral (مرجانی)
- **حالت‌ها:** Light Mode + Dark Mode
- **زبان:** فارسی (RTL) + انگلیسی (LTR)

## 🛠 تکنولوژی

- **Frontend:** Next.js (React)
- **Backend:** Node.js API Routes
- **Database:** SQLite (قابل ارتقا به PostgreSQL)
- **Authentication:** JWT + bcrypt

## 🚀 شروع به کار

```bash
# نصب وابستگی‌ها
npm install

# اجرای دیتابیس
npx prisma migrate dev

# اجرای پروژه
npm run dev
```

سپس `http://localhost:3000` را باز کنید.
