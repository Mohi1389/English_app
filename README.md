# Learn with Mohanna 🌊

یک اکوسیستم کامل، مدرن و هوشمند یادگیری زبان انگلیسی برای فارسی‌زبان‌ها — از سطح مبتدی تا متوسط.

## 🎯 هدف

کمک به فارسی‌زبان‌ها برای یادگیری زبان انگلیسی از طریق آموزش، تمرین، هوش مصنوعی، آزمون، ارتباط کاربران و پیگیری پیشرفت — قدم‌به‌قدم و لذت‌بخش.

## ✨ امکانات

- 🏠 **صفحه اصلی** — معرفی برند با پیام «Learn English with confidence»، دکمه‌های شروع یادگیری و تعیین سطح، معرفی امکانات
- 📊 **داشبورد شخصی** — نام کاربر، سطح، درصد پیشرفت، لغات ذخیره‌شده، آزمون‌ها، مکالمات AI، روزهای یادگیری و «مسیر یادگیری من»
- 📚 **لغات تعاملی** — هر لغت با معنی فارسی، تلفظ، جمله نمونه، ترجمه، سطح سختی، لغات مرتبط، ذخیره و تمرین با AI
- 🔍 **دیکشنری هوشمند** — جستجوی کلمه با معنی، تلفظ، مثال، توضیح فارسی و «تمرین با هوش مصنوعی»
- 🤖 **دستیار هوشمند فارسی** — کاملاً فارسی‌محور؛ پاسخ فارسی، اصلاح گرامر با دلیل، ترجمه، برنامه یادگیری؛ تاریخچه مکالمات ذخیره می‌شود
- 📝 **آزمون‌ها** — واژگان، گرامر، تعیین سطح و ترکیبی با امتیاز، نقاط قوت/ضعف و پیشنهاد قدم بعدی
- 👥 **انجمن امن** — اتاق‌های موضوعی، گزارش محتوا، مسدود کردن کاربران و فیلتر محتوای نامناسب
- 🎬 **فیلم و انیمیشن** — زیرنویس دو زبانه، استخراج لغات، توضیح جمله و ذخیره عبارت
- 👤 **پروفایل** — آمار، دستاوردها و لینک‌های ادامه یادگیری
- ⚙️ **تنظیمات** — حالت تاریک/روشن، زبان فارسی/انگلیسی، هدف روزانه و اعلان‌ها
- 🔐 **حساب کاربری** — ثبت‌نام (نام، ایمیل، رمز، بازه سنی، سطح، هدف)، ورود، خروج و بازیابی رمز

## 🎨 هویت رنگی

- **رنگ اصلی:** Ocean Blue (آبی اقیانوسی)
- **رنگ مکمل:** Coral (مرجانی)
- **دو حالت:** Light Mode + Dark Mode (آبی عمیق اقیانوسی، نه مشکی)
- **زبان:** فارسی (RTL) + انگلیسی (LTR) با پیش‌فرض فارسی

## 🧱 تکنولوژی

- **Frontend:** Next.js (React)
- **Backend:** Node.js API Routes
- **Database:** SQLite (قابل ارتقا به PostgreSQL)
- **Authentication:** JWT + bcrypt
- **هوش مصنوعی:** OpenAI (قابل وصل با `OPENAI_API_KEY`)

## 🚀 راه‌اندازی

```bash
# نصب وابستگی‌ها
npm install

# راه‌اندازی دیتابیس و اعمال migration
npx prisma migrate dev

# (اختیاری) افزودن داده نمونه
npx prisma db seed

# اجرای نسخه توسعه
npm run dev
```

سپس `http://localhost:3000` را باز کن.

برای فعال کردن دستیار هوشمند AI، مقدار `OPENAI_API_KEY` را در فایل `.env` تنظیم کن.
